# Nom du Projet : Boutique App (React)

##  Description
Ce projet est une application web développée avec React. Elle permet de consommer une API externe (FakeStoreAPI) pour afficher une liste de produits, rechercher un produit par son ID, et consulter les détails d'un produit spécifique.

##  Technologies utilisées
*   **React.js** (Bibliothèque front-end)
*   **React Router** (Navigation entre les pages)
*   **CSS3** (Mise en page et style)
*   **Git & GitHub** (Gestion de versions et collaboration)

##  Prérequis
Avant de lancer le projet, assurez-vous d'avoir installé :
*   [Node.js](https://nodejs.org/) (version 14 ou supérieure)
*   [Git](https://git-scm.com/)
